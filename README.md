# Power BI Final Guided Project

---

## Overview
This repository contains the final guided project from the **Power BI for Beginners Bootcamp**.  
It demonstrates end-to-end data analysis and visualization using Power BI, combining data cleaning, modeling, DAX, and dashboard creation.

---

## Topics Covered
1. Installing Power BI & First Visualization  
2. Power Query (data import and transformation)  
3. Creating and Managing Relationships  
4. DAX (calculated columns and measures)  
5. Drill Down and Hierarchies  
6. Conditional Formatting  
7. Bins and Lists  
8. Popular Visualizations  
9. Final Guided Project (complete dashboard)

---

## Power BI Dashboard Features
- **Demographics:** Country of survey takers (Canada, India, UK, US, Others)  
- **KPIs:** Count of survey takers (630), Average age (29.87)  
- **Salary Analysis:** Average salary by job title and gender  
- **Satisfaction Metrics:** Work-life balance (5.74/10), Salary satisfaction (4.27/10)  
- **Programming Preferences:** Favorite languages (Python, R, C/C++, JavaScript, Java)  
- **Interactive Filters:** Country, job title, gender, and age slicers  

---

## Key Insights
- **Data Scientists** earn the highest average salary among surveyed roles.  
- **Work-life balance satisfaction (5.74/10)** is higher than salary satisfaction (4.27/10).  
- **Python** dominates as the favorite programming language across job titles.  
- Survey participation reached **630 respondents**, providing a strong dataset for analysis.  
- Geographic distribution shows strong representation from **India, US, UK, and Canada**.  

---

## How to Use
1. Download the `.pbix` file from this repository.  
2. Open it in Power BI Desktop.  
3. Explore the dashboard using slicers and filters.
